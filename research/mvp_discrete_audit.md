# Discrete MVP: five construction tasks

For each task, the objective is the stated natural scalar; parameters below are instance configuration, not separate benchmark families. “Recomputed” means I independently checked the displayed witness, not merely read the repository’s score. Human construction and later solver/AI records are kept separate.

| Task / score | Two concrete configurations and human baselines | Recomputed? | Decision / gap |
|---|---|---|---|
| **Golomb ruler** — for fixed number of marks $m$, minimize length $L=a_m-a_1$, subject to all positive pairwise differences being distinct. | **(a)** $m=10$: marks `0,1,6,10,23,26,34,41,53,55`, $L=55$; attributed to William Mixon (1972), optimal. **(b)** $m=12$: marks `0,2,6,24,29,40,43,55,68,75,76,85`, $L=85$; John P. Robinson (1979), optimal. Source with construction and proof-history: [Dimitromanolakis, *Analysis of the Golomb ruler and Sidon set problems* (2002), ch. 2](https://www.cs.toronto.edu/~apostol/golomb/main.pdf); source lists Mixon’s proof for 8–11 and Robinson’s 12/13 proof in 1979. | **Both witnesses recomputed:** all $\binom m2$ differences are distinct and final marks match stated lengths. | **Accept.** Keep $m$ fixed per instance; do not conflate minimizing length at fixed $m$ with maximizing marks at fixed length. These are already solved calibration sizes, so add a larger open size only if the desired difficulty is search rather than calibration. |
| **Forbidden-cycle extremal graph** — for fixed $n$ and cycle family $H$, maximize $e(G)$ over simple $n$-vertex $H$-free graphs. $C_4$ and $\{C_3,C_4\}$ are configurations of one objective. | **(a)** $H=\{C_4\}, n=30$: $ex(30,C_4)=85$; [Afzaly–McKay sparse6 witness](https://users.cecs.anu.edu.au/~bdm/data/extremal/c4_n30e85.s6). **(b)** $H=\{C_3,C_4\}, n=30$: $ex(30,\{C_3,C_4\})=76$; [Afzaly–McKay sparse6 witness](https://users.cecs.anu.edu.au/~bdm/data/extremal/c34_n30e76.s6). The table says entries without “≥” give exact Turán number and all extremizers; witnesses are linked in sparse6. | **No** independent graph/cycle verification. Table reports exact values and supplies witnesses. | **Accept.** Use the two entries as config checks, with edge count as score. If the benchmark needs a less solved target, pick a parameter where the database marks only a lower bound; do not label that value optimal. |
| **Ordinary covering design** — for fixed $(v,k,t)$, minimize the number of $k$-blocks covering every $t$-subset. | **(a)** $C(8,4,3)=14$: Steiner $S(3,4,8)$, exactly 14 blocks by counting; construction/existence within Hanani, [“On quadruple systems” (1960)](https://doi.org/10.4153/CJM-1960-013-3). **(b)** $C(10,4,3)=30$: Steiner $S(3,4,10)$, exactly 30 blocks; same construction theorem/source. Hanani proves $S(3,4,v)$ exists exactly for $v\equiv2,4\pmod6$; these parameter sets attain the counting bound ${v\choose3}/{4\choose3}$. | **No** block lists independently reconstructed/checked in this pass; existence and theorem are sourced, and values follow the exact counting bound. | **Conditional/calibration.** These are legitimate natural-scalar instances, but both hit the elementary lower bound and are likely too easy as discovery tasks. For a search benchmark beyond calibration, choose a non-Steiner tuple from the [La Jolla / Covering Repository records](https://www.coveringrepository.com/default.aspx) and freeze its human block-list artifact, contributor and date; I have not certified a suitable nontrivial tuple here. |
| **Uniform covering array** — for fixed $(t,k,v)$, minimize rows $N$ of a $v$-ary array with $k$ columns so every selection of $t$ columns contains all $v^t$ tuples. | NIST’s IPOG-F result table supplies actual arrays: **(a)** $CA(3,10,2)$, $N=18$, [table row and array download](https://math.nist.gov/coveringarrays/ipof/tables/table.3.2.html) (click $k=10$); **(b)** $CA(3,20,2)$, $N=25$, same source (click $k=20$). Source is the NIST-generated archive [Forbes, Lawrence, Lei, Kacker & Kuhn, “Refining the In-Parameter-Order Strategy for Constructing Covering Arrays” (2008)](https://math.nist.gov/coveringarrays/ipof/ipof-abstract.pdf); the table calls these IPOG-F outputs and makes files downloadable in its custom format. | **No** row coverage independently rechecked; row counts were checked against NIST table. | **Accept.** Human-construction data are directly downloadable; minimize row count, while the array verifier checks the covering condition. NIST notes its separate large-$k$ smallest-size table does not include arrays, so use the precomputed array library, not size-only table, as the baseline artifact. |
| **Sum–difference I** — for finite $A\subset\mathbb Z$, maximize $\log(|A+A|/|A|)/\log(|A-A|/|A|)$. | Same human construction is valid under both caps: **(a)** $|A|\le17$, span $\le29$; **(b)** $|A|\le32$, span $\le29$. Human baseline $A=\{0,1,2,4,5,9,12,13,14,16,17,21,24,25,26,28,29\}$, attributed by Martin–O’Bryant to Freiman–Pigarev, [Martin & O’Bryant (2006)](https://arxiv.org/abs/math/0608131). Lin–Li (2026) now claim the global supremum 2 with AI-agent assistance; this is not the human baseline. The two caps above are finite search instances, not claims that these caps capture the global supremum. |

## Cage-number check: (n(4,10))

The statement $n(4,10)\le320$ is **not wrong**: it is an upper bound from the explicit 320-vertex 4-regular girth-10 graph of Exoo, Goedgebeur, Jooken, Stubbe and Van den Eede, [2025 preprint, revised 2026](https://arxiv.org/abs/2511.07247). Their table reports lower bound 243, previous upper bound 384, new upper bound 320; the 320 construction uses base group `SmallGroup(40,10) = C5 × D4`. The Moore tree count itself is 242; the paper’s strengthened tabulated lower bound is 243. I found no primary source for a 288-vertex $(4,10)$-graph; the current source chain checked here reports 320 as the best upper bound, so treat “288 known” as unverified and likely a confusion with another cage datum. A cage task is separate from the accepted F-free *edge-maximization* task: it minimizes vertex count with degree/girth constraints and should not be silently substituted.

## Direct source notes

- Golomb record table / proof history: [Dimitromanolakis (2002), ch. 2](https://www.cs.toronto.edu/~apostol/golomb/main.pdf); it explicitly attributes the 8–11 optimal proofs to Mixon and 12–13 to Robinson. The 10- and 12-mark records above are reproduced from the source’s known-ruler table/standard cited records; 12-mark length is 85 (not 106, which is the 13-mark ruler).
- Graph witnesses and data semantics: [Afzaly–McKay database](https://users.cecs.anu.edu.au/~bdm/data/extremal.html); it explicitly marks exact (ex(n,H)) entries and links the graphs in sparse6 format.
- Covering design theorem: [Hanani (1960), DOI and original paper](https://doi.org/10.4153/CJM-1960-013-3). For $S(3,4,v)$, a Steiner system is itself a covering and meets the counting lower bound.
- Covering-array definition and NIST generated instances: [NIST definition](https://math.nist.gov/coveringarrays/coveringarray.html), [NIST IPOG-F parameter table](https://math.nist.gov/coveringarrays/ipof/tables/table.3.2.html), [Forbes et al. (2008) abstract](https://math.nist.gov/coveringarrays/ipof/ipof-abstract.pdf).
- Sum–difference set provenance and exact counts: [Martin–O’Bryant (2006)](https://arxiv.org/abs/math/0608131), [AlphaEvolve paper](https://arxiv.org/abs/2511.02864).
