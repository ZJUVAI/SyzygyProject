Find a smallest set of 10-bit binary words whose radius-one Hamming balls cover all 1024 binary words. Return JSON as `{"codewords": [integer, ...]}`, where each integer is in 0..1023 and encodes one 10-bit word. The evaluator rejects duplicates and independently checks every word in the universe. The objective is the number of codewords; do not use a claimed score as a substitute for a covering code.
