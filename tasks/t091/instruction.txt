Task T091-C01: minimize the number of rows in a binary orthogonal array with 63 columns and strength 4. Return JSON as {"rows":[integer masks]}, where bit j of each nonnegative integer is column j. Row repetition is allowed. For every set of four columns, all 16 patterns must occur exactly N/16 times. N must be a positive multiple of 16; Rao's bound implies N >= 2032. Start from the standalone random-greedy F_2^14 construction in init_program.py. It selects labels so no XOR of up to four distinct labels is zero, then enumerates all linear forms. Search may test row deletions but must not read human/reference/best assets. Do not include a claimed score. The evaluator checks all parity characters on subsets of up to four columns exactly.
