Find a largest binary constant-weight code for the fixed configuration A(17,4,5).

Return JSON with `codewords`, a list of distinct 17-character strings over `0` and `1`. Every word must contain exactly five `1` characters. Every two distinct words must have Hamming distance at least four.

The score is the number of codewords. The checker reads all words and recomputes the score. It checks every unordered pair exactly using integer bit operations. It ignores any claimed score fields.

Start from `init_program.py`. Do not read comparison constructions under `data/source` or `data/reference`. Improve the construction by your own search. The target is unrestricted over all binary words with the fixed length and weight.

Read the configuration from `MATHBENCH_CONFIG_ID` and the random seed from `MATHBENCH_SEED`. Use deterministic defaults. Generation has a 300-second limit. Verification has a separate 60-second limit. Memory is limited to 4 GiB and one compute thread.
