Construct a simple undirected connected graph with maximum degree at most 3 and diameter at most 5. Maximize the number of vertices.

Return JSON data as {"n": integer, "edges": [[u, v], ...]}. Vertices must be exactly 0 through n-1. Each edge is an unordered pair of distinct vertices. Do not repeat an edge. The evaluator checks degree, connectivity, and all shortest-path distances, then uses n as the objective. It ignores claimed scores.

There is one configuration, T044-C01. The Moore bound gives n <= 94 for this parameter, but it does not establish the exact maximum. The checked published record is 70.
