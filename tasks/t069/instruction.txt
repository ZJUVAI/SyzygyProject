Solve the fixed Mona Lisa 100K Euclidean traveling salesman instance. Return a JSON object with `tour`, a list of exactly 100000 distinct integers from 0 through 99999. Each integer identifies a city by its zero-based row in the pinned input file. The list is a closed cycle: include the edge from the last city back to the first. Minimize the exact sum of TSPLIB EUC_2D edge lengths, rounded to the nearest integer. The evaluator recomputes the score and ignores claimed scores. Do not read human or reference tour files. The public coordinate input is available to the task runner. Keep `run_code()` within the generation budget.
