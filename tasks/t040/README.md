# T040: Independent sets in strong powers of C7

For the fixed power `k=5`, maximize the number of distinct words in an independent set of the strong power `C7^k`. A word is a vector in `{0,...,6}^k`. Two words conflict when their cyclic distance is at most one in every coordinate. The checker verifies every unordered pair exactly.
