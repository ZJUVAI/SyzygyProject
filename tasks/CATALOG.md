# 正式任务目录

共 100 道任务。编号先按研究方向分组，再按数学对象和构造目标排序。
组内优先将使用相近构造或约束的任务放在一起。此顺序不表示难度。

旧编号指远端提交 `c9f9355`。旧运行记录须使用对应的 Git 版本重放。
新编号不兼容旧编号。参数、配置后缀、构造和成绩均保持不变。
