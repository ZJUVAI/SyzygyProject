Build a long induced path in the 9-dimensional hypercube Q9. A vertex is an integer from 0 through 511, with its 9-bit binary representation as coordinates. Return JSON with a `vertices` list in path order. Consecutive vertices must differ in exactly one bit. Every vertex must be distinct, and every nonconsecutive pair must differ in at least two bits. Maximize the edge count, `len(vertices)-1`. Do not return a cycle. The evaluator recomputes validity and score exactly and ignores declared scores.

Do not use external comparison witnesses in the initial or search programs. Use MATHBENCH_SEED for deterministic randomness. Keep generation within 300 seconds; exact verification has a separate 60-second limit, with 4 GiB memory and one thread. The official checker tests every vertex pair.
