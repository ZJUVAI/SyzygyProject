Choose 12 distinct points in the plane to minimize the largest squared pair distance divided by the smallest squared pair distance. Return a JSON object with `points`, a list of exactly 12 coordinate pairs. Each coordinate must be an integer or an exact rational string such as `"3/2"`; floating-point values are not accepted. There are no coordinate bounds, container, or collinearity restriction. The evaluator computes all 66 squared distances with exact rational arithmetic and ignores claimed scores. Do not read human or reference files. The initial program returns a 4 by 3 integer grid.
