Construct a binary strength-four covering array with 20 columns. Minimize the number of rows. Each entry must be the integer 0 or 1. For every choice of four distinct columns, all 16 binary 4-tuples must occur in at least one row. Return JSON data as {"array": [[...], ...]}. Do not include duplicate rows. The evaluator computes coverage and row count from the returned array; do not rely on a claimed score. Arrays may contain at most 6,196 rows. This is a safe cap because a covering array with 6,196 rows is given by all 20-bit vectors of Hamming weight at most four; the cap removes only larger, noncompetitive arrays. The current public parameters are visible and are not a hidden test set.

Define run_code() with no arguments. Use MATHBENCH_CONFIG_ID and MATHBENCH_SEED when needed. Generation has a 300-second limit. Verification has a separate 60-second limit. Memory is limited to 4 GiB, with one CPU thread. Human and public-record witnesses are external comparison data and must not enter the model workspace.
