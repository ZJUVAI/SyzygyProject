Construct a large binary single-deletion-correcting code of length 16. Return a JSON object with `codewords`, a list of distinct integers from 0 through 65535. Two different codewords are incompatible if deleting one bit from each can produce the same 15-bit sequence. The evaluator checks all such outputs exactly and maximizes the number of codewords. Do not read the human or reference witness. The initial program is a simple valid one-word code. The public task has fixed length 16 and one deletion. Return only JSON-compatible values from `run_code()`.
