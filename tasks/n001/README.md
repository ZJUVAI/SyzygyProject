# N001：C7 五次强积中的独立集

给定七点环 C7，构造 C7 五次强积中的独立集。目标是最大化词数。每个词有五个 0 至 6 的整数。任意两词必须在至少一个坐标上的循环距离大于 1。已知公开见证有 367 个词；这不证明最优。

数据文件 `data/human_reference.json` 保存人类见证。

# N001: Independent sets in the fifth strong power of C7

Build an independent set in the fifth strong power of the seven-cycle C7. Maximize the number of words. Each word contains five integers from 0 through 6. Each pair must have cyclic distance greater than 1 in at least one coordinate. A published witness has 367 words. This does not prove optimality.
