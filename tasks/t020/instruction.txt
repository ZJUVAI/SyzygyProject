Construct an ordinary addition chain for the configured target n. Configuration T020-C01 uses n = 2^192 - 2^64 - 3; T020-C02 uses n = 2^221 - 5; T020-C03 uses n = 2^521 - 3. Return JSON as {"chain": [1, ... , n]}. Each entry after 1 must be the sum of two earlier entries, with the same earlier entry allowed twice. Entries must be positive integers in strictly increasing order. Minimize the number of additions, which is len(chain)-1. Do not use subtraction or modular reduction. Do not include a claimed score; the checker computes the objective.


Program interface: define run_code() with no arguments and return the construction as JSON-compatible data. The trusted evaluator recomputes the objective. Candidate-reported scores do not affect it. Read MATHBENCH_CONFIG_ID and MATHBENCH_SEED if needed. The generation limit is 300 seconds, with 4 GiB virtual memory and one numerical thread. Verification has a separate 60-second limit. Final scores require exact or conservative interval verification. Compatibility feedback is J/H for maximization or H/J for minimization, where H is the frozen external reference. Start from the supplied initial program.
