Minimize the number of compare-exchange elements in a sorting network with the configured number of input wires. Each comparator is [left, right], uses zero-based wire IDs 0..inputs-1 with left < right, and executes in list order. Return JSON as {"comparators": [[left, right], ...]}. The evaluator checks all 2^inputs binary inputs using the zero-one principle and recomputes the comparator count. Do not use the public reference network or its saved witness. The self-contained initial program is an odd-even transposition network. The fixed-step search baseline starts only from the network produced by init_program.py and proposes random comparator deletions, retaining a candidate only after exact verification. evolution.py starts from the same seed and proposes deletions, replacements, or order swaps; it also retains only exactly verified candidates. Do not read human.py, reference.py, or data/reference. Your entry point must be run_code() with no arguments and return JSON-compatible data. Read MATHBENCH_CONFIG_ID and MATHBENCH_SEED. Generation has a 300-second limit; verification has a separate 60-second limit.
