The exported public graph file is relative to the task workspace at data/source/gd96a.rmf. It uses RMF text rows: the header is `p ghct n m`, followed by `m` rows `e u v 1` with 1-based vertex IDs. Return JSON as {"ordering": [vertex_id, ...]} with every vertex ID from 1 through 1,096 exactly once. The evaluator reads the pinned graph and recomputes the integer objective. Do not use comparison orderings or the reference program. The initial program returns the identity ordering. The traditional search baseline uses randomized reverse-Cuthill-McKee starts and adjacent-swap descent. Your entry point must be run_code() with no arguments and return JSON-compatible data. Read MATHBENCH_CONFIG_ID and MATHBENCH_SEED. Generation has a 300-second limit; verification has a separate 60-second limit.
