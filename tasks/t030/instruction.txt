Minimize the number of colors used to properly color the fixed DIMACS graph DSJC1000.5. The graph input is `data/DSJC1000.5.bits`; it stores a headerless upper-triangle bitset for 1000 vertices and 249826 undirected edges. Pair `(u, v)` uses bit index `v*(v-1)//2+u` for `0 <= u < v < 1000`. Bits are least-significant-bit first within each byte. Unused high bits in the last byte are zero. Vertices are indexed from 0 to 999. Return `{"colors": [1000 integer color labels]}` from `run_code()`. Every edge must join vertices with different colors. The evaluator checks every edge and recomputes the number of distinct color labels. Generation budget: 300 seconds. Verification budget: 60 seconds. Memory: 4 GiB. CPU threads: 1. Use `MATHBENCH_SEED` for seeded randomness and `MATHBENCH_CONFIG_ID` for the selected configuration.
