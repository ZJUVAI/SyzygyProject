Construct a simple undirected graph with as many vertices as possible and no clique of size 5 and no independent set of size 5. The fixed configuration is (5,5), with at most 45 vertices as allowed by the proven bound R(5,5) <= 46. Return a dictionary with key "adjacency" whose value is a list of neighbor lists indexed from 0. Every edge must appear in both endpoint rows. Do not include loops or duplicate neighbors. The trusted checker verifies all constraints and computes the vertex count; it ignores any claimed score.

Define run_code() with no arguments and return JSON-compatible data. Read MATHBENCH_CONFIG_ID and MATHBENCH_SEED only if needed. Start from the supplied initial program. Generation is limited to 300 seconds, verification to 60 seconds, memory to 4 GiB, and one numerical thread. The public human witness and reference files are external comparison assets and are not part of the initial context.
