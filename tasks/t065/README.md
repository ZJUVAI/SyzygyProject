# T065: maximum unit-distance pairs for 100 planar points

## 中文

### 数学定义和参数

配置 `T065-C01` 固定 100 个互不相同的平面点。目标是最大化距离恰好为 1 的无序点对数 \(u(100)\)。检查器接受一个不可约多项式选定的公共实代数数域，并以有理区间指定其一个实根 \(\alpha\)。每个坐标写成 \(\alpha\) 的有理系数多项式。检查器会精确计算全部 4,950 个平方距离并判断是否等于 1。它不会用浮点容差。

这种表示不把候选限制在 Moser 格点或有理平面。有限个点之间的单位距离等式和点互异条件组成有理多项式方程及严格不等式。只要实配置可行，该有限半代数条件也有实代数点；有限多个坐标又包含在一个本原元生成的实数域中。因此这种输入表示可覆盖任意实平面点配置的单位距离模式。

### 来源和当前记录

Engel 等人的 arXiv:2406.15317v3（2025-06-13）表 2 报告 `n=100` 时搜索到 439 条单位距离，并找到 22 个同构类。搜索使用 Moser 格点上的多样化回溯 beam search。论文没有给出这 100 个点的完整列表。作者仓库 README 链接的 Figshare 数据在本环境不可取（HTTP 403/WAF），所以 439 只记为未复现公开报告，不放进 reference 程序。

公开报告不能证明最大值为 439。Alexeev、Mixon、Parshall 的 arXiv:2412.11914v2 证明精确值到 `n≤21`。2026 年 10 月的更新调查仍列 439 为已报告的 `n=100` 最大下界，并指出同期有理平面搜索没有给出小规模 `n=100` 对照值。我们没有找到匹配 439 的全局上界证明。

冻结的人类基线是经典三角格中的 `10×10` 点块：

\[
p_{i,j}=(i+j/2,\sqrt3 j/2),\qquad 0\le i,j<10.
\]

格中三个正向单位差向量分别贡献 90、90、81 对，总数是 261。它是可复现的传统人类构造，不是作者 439 搜索结果，也不声称是公开最优纪录。参考程序和人类程序都精确复现该 261 点集，并与未复现的 439 报告分开。

### 精确代数表示

见证数据用 \(\alpha=\sqrt3+\sqrt{11}\)，其本原多项式为

\[
\alpha^4-28\alpha^2+64=0,
\]

区间 `[5, 51/10]` 唯一选定正根。每个坐标以 \(1,\alpha,\alpha^2,\alpha^3\) 的有理线性组合表示。由

\[
\sqrt3=(\alpha^3-20\alpha)/16,
\]

可将上面的三角格坐标精确编码为这个公共数域内的多项式。检查器以多项式余数是否恰为 1 作为单位距离判据。

### 程序

- `check.py`：验证字段、不可约多项式、实根隔离区间、点不重复，并精确重算全部点对。
- `init_program.py`：自包含的 100 个间距为 2 的共线点，给出有效的 0 分起点，不读取其他构造。
- `baseline.py`：穷举 100 的因子对，比较所有矩形三角格点块的三个单位方向边数。
- `evolution.py`：在因子对空间内做定种子变异和精英选择。它只搜索矩形三角格子族，不代表对所有平面构造的全局搜索。
- `human.py`：从保存的三角格公式恢复传统人类基线 261。
- `reference.py`：固定复播该 261 点人类基线。

默认搜索使用固定迭代数；设置 `MATHBENCH_SEARCH_SECONDS` 可启用共享搜索截断。程序从 `MATHBENCH_CONFIG_ID` 读取配置，从 `MATHBENCH_SEED` 读取种子。共用预算为生成 300 秒、验证 60 秒、4 GiB、单线程。搜索和初始程序不读 `data/reference/` 或 `data/source/`。

## English

### Definition and configuration

`T065-C01` fixes exactly 100 distinct points in the plane. Maximize \(u(100)\), the number of unordered point pairs at distance exactly 1. The checker accepts a common real algebraic number field specified by an irreducible polynomial and a rational interval selecting one real root \(\alpha\). Each coordinate is a rational polynomial in \(\alpha\). It checks all 4,950 squared distances by exact arithmetic. It uses no floating-point tolerance.

This representation does not restrict candidates to the Moser lattice or the rational plane. Any finite unit-distance pattern is described by polynomial equalities and strict inequalities over \(\mathbb Q\). If that finite semialgebraic system has a real solution, it has a real algebraic solution; finitely many algebraic coordinates lie in one number field generated by a primitive element. Thus the format can represent the unit-distance pattern of any feasible real configuration.

### Sources and current record

Engel et al., arXiv:2406.15317v3 (2025-06-13), Table 2 reports 439 unit-distance pairs at `n=100` and 22 found isomorphism classes. Their method is a diverse backtracking beam search on the Moser lattice. The paper does not print the full 100-point witness. The Figshare dataset linked by the authors' repository returned HTTP 403/WAF in this environment. Therefore, 439 is recorded as an unreproduced public report and is not loaded by `reference.py`.

The report is not an optimality proof. Alexeev, Mixon, and Parshall, arXiv:2412.11914v2, prove exact values through `n<=21`. An October 2026 survey still lists 439 as the reported `n=100` value and notes that the concurrent rational-plane exploration gives no small-n=100 comparison. No matching global upper bound for 100 points was found.

The frozen human baseline is a classical `10×10` patch of the triangular lattice:

\[
p_{i,j}=(i+j/2,\sqrt3 j/2),\qquad 0\le i,j<10.
\]

Its three positive unit directions contribute 90, 90, and 81 pairs, for 261 total. This is a reproducible traditional construction, not the authors' 439 search result and not a claim of the public best. The human and reference programs replay this 261-point set and keep the unreproduced 439 report separate.

### Exact algebraic encoding

The witness uses \(\alpha=\sqrt3+\sqrt{11}\), with primitive polynomial \(\alpha^4-28\alpha^2+64\) and isolating interval `[5, 51/10]`. Coordinates are rational combinations of \(1,\alpha,\alpha^2,\alpha^3\). The identity \(\sqrt3=(\alpha^3-20\alpha)/16\) gives an exact encoding of the triangular-grid points. The checker tests whether each squared-distance residue is exactly 1.

### Programs

- `check.py` validates the field, irreducibility, root interval, point distinctness, and all point pairs.
- `init_program.py` is a standalone valid seed of 100 collinear points spaced by 2, with score 0.
- `baseline.py` scans all factor pairs of 100 and compares edge counts for rectangular triangular-lattice patches.
- `evolution.py` uses seeded mutation and elitist selection over those factor pairs. It searches only this patch family, not the full plane configuration space.
- `human.py` rebuilds the traditional 261-point baseline.
- `reference.py` replays that fixed 261-point witness.

Search uses fixed iteration counts by default. `MATHBENCH_SEARCH_SECONDS` enables the shared exploration cutoff. Programs read `MATHBENCH_CONFIG_ID` and `MATHBENCH_SEED`. Shared budgets are 300 seconds for generation, 60 seconds for verification, 4 GiB of memory, and one thread. The initial and search programs do not read `data/reference/` or `data/source/`.
