Find a large set of directions in five-dimensional Euclidean space such that every pair has angle at least 60 degrees. Maximize the number of directions. Return JSON as {"directions": [[q1,q2,q3,q4,q5], ...]}; each coordinate must be an integer or a rational string such as "-2/3". The verifier treats each vector as a direction and normalizes it exactly. A zero vector is invalid. The checker accepts only rational-coordinate witnesses; this is a representation of candidate witnesses, not a claim that all real configurations have rational coordinates. Do not return a claimed score. The best verified human construction has 40 directions. The unrestricted optimum is not known; published bounds are 40 through 44.
