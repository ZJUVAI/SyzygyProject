Find a low-copy tiling of an axis-aligned rectangle by the fixed P1 11-omino.

Return JSON with integer `width`, integer `height`, and a nonempty `placements` array. Every placement has integer `x`, integer `y`, and integer `orientation` in 0..7. Each orientation code selects one of the eight D4 orientations: bit 0 transposes x/y, bit 1 reflects x, and bit 2 reflects y. The tile is translated so its oriented bounding box starts at (x,y).

The fixed tile has 11 cells. Tile translations, rotations, and reflections are allowed. The target rectangle dimensions are free. Minimize the number of copies. The checker independently checks exact cell coverage and ignores declared score fields.

Start from a simple valid construction. Search deterministically from `MATHBENCH_SEED`. Do not read the human or reference witness files. Expose `run_code()`.
