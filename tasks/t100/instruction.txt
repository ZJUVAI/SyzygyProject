Build a simple undirected graph with vertex set {0, 1, ..., 49} and exactly 700 edges. Return JSON as {"vertices": 50, "edges": [[u, v], ...]}. Each edge must join two different vertex IDs. Do not repeat an edge, including with its endpoints reversed. The objective is to minimize the number of triangles. The evaluator counts triangles from the returned edge list. Do not include or rely on a claimed score. Your search may use any graph on these fixed vertices and edge count. Expose a no-argument run_code() function and use MATHBENCH_SEED for deterministic randomness.
