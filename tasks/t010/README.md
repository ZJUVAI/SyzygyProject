# T010: Maximum size of a binary code A(n,d)

## 中文

### 目标与配置

构造长度为 `n`、任意不同码字距离至少为 `d` 的二元码，并最大化码字数。C01 为 `(17,6)`；新增 C02 为 `(23,10)`；新增 C03 为 `(25,10)`。新配置已通过 Sol 验收（2026-11-07）。

### 人类构造与公开记录

三组配置均有传统 BCH 基线。以二元原始窄义 BCH `[31,11,≥11]` 码的生成多项式 `g(x)=x^20+x^18+x^17+x^13+x^10+x^9+x^7+x^6+x^4+x^2+1` 编码。将前 7 个或前 5 个坐标缩短，得到 16 或 64 个码字；再删除下一个坐标，得到长度 23 或 25。缩短保留距离，删除一个坐标最多使距离减少 1。保存的两个见证精确检查到最小距离 10。

Ota、Osa 与 Harada 的论文给出 `(22,84,9)` 和 `(24,196,9)` 的完整十进制码字列表，并提供穷举验证程序。对每个码字追加整体奇偶校验位，分别得到本任务的 `(23,84,10)` 和 `(25,196,10)` 见证。论文说明奇数距离满足 `A₂(n,d)=A₂(n+1,d+1)`。附件源列表与扩展后的本地 JSON 均已保存，验证器对所有码字对精确计算距离。

Brouwer 的公开表给出 `84 ≤ A₂(23,10) ≤ 150` 和 `196 ≤ A₂(25,10) ≤ 466`。两个配置均未证明最优。论文未说明是否使用 AI 工具，因此档案不对其来源方式作推断。

## English

### Goal and configurations

Construct a binary code of length `n` with pairwise distance at least `d`. Maximize its size. C01 is `(17,6)`. New C02 is `(23,10)`, and new C03 is `(25,10)`. The new configurations are accepted by Sol on 2026-11-07.

### Human constructions and public records

Each instance has a classical BCH baseline. Encode with the primitive narrow-sense binary BCH `[31,11,≥11]` code generated by `g(x)=x^20+x^18+x^17+x^13+x^10+x^9+x^7+x^6+x^4+x^2+1`. Shorten the first seven or five coordinates to obtain 16 or 64 words, then delete the next coordinate to get length 23 or 25. Shortening preserves distance, and puncturing can reduce distance by at most one. Exact checks find minimum distance 10 for both saved witnesses.

Ota, Osa, and Harada publish complete decimal word lists for `(22,84,9)` and `(24,196,9)`, with an exhaustive verifier. Appending an overall parity bit gives the `(23,84,10)` and `(25,196,10)` witnesses. Their paper states `A₂(n,d)=A₂(n+1,d+1)` for odd `d`. Both source lists and parity-extended witnesses are saved locally. The checker recomputes every pairwise distance exactly.

Brouwer's table gives `84 ≤ A₂(23,10) ≤ 150` and `196 ≤ A₂(25,10) ≤ 466`. Neither instance is proved optimal. The paper does not state whether AI tools assisted, so this package does not infer that provenance.
