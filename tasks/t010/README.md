# T010: Maximum size of a binary code A(n,d)

## 中文

T010-C01 要求构造长度为 17 的二元码。任意两个不同码字的汉明距离至少为 6。目标是最大化码字数。检查器精确计算每对码字的距离。

人类基线、公开构造及复算结果见[来源记录](data/bestknown.json)。

## English

T010-C01 fixes code length 17 and minimum pairwise Hamming distance 6. Maximize the number of codewords. The checker computes the exact distance for every pair.

See the [source records](data/bestknown.json) for the human baseline, public construction, and replay results.
