Build a large independent set in the selected strong power of C7. T011-C01 uses five coordinates. Return JSON-compatible data with one key, "words", whose value is a list of words. Every word must have the selected number of integer symbols from 0 to 6. Words must be distinct. Each pair must differ by cyclic distance at least 2 in at least one coordinate. Maximize the number of words. The checker recomputes validity and score exactly; it does not trust a claimed score.

The supplied initial program is the only required starting point; do not use human or record witness files as search inputs.

Program interface: define run_code() with no arguments. Read MATHBENCH_CONFIG_ID and MATHBENCH_SEED if needed. Generation limit is 300 seconds, verification has a separate 60-second limit, memory is 4 GiB, and one numerical thread is allowed. Formal scores require exact full-pair verification.
