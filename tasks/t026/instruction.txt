Construct a coloring of the consecutive positive integers 1 through N with at most six colors. Maximize N. A coloring is valid only when no same-color x and y, including x = y, have x + y in the same color. Return JSON with exactly this data shape: {"n": N, "colors": [c_1, ..., c_N]}, where c_i is an integer from 0 through 5 and array position i-1 gives the color of integer i. Do not return color classes. Your program must define run_code() and return this object. The evaluator computes N from the array and ignores any claimed score or metadata. The default resource budget is 300 seconds for generation, 60 seconds for verification, 4 GiB of memory, and one CPU thread.
