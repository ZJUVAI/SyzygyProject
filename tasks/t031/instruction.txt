Find a short string over the fixed alphabet {1, 2, 3, 4, 5, 6, 7}. The string must contain every permutation of these seven symbols as a contiguous substring of length 7. The objective is to minimize the string length. Return {"word": "..."} from run_code(). The evaluator checks all 5,040 permutations and recomputes the string length. It ignores claimed scores. Use MATHBENCH_CONFIG_ID for the configuration and MATHBENCH_SEED for seeded search. The initial program is a simple valid construction. Generation budget: 300 seconds. Verification budget: 60 seconds. Memory: 4 GiB. CPU threads: 1.
